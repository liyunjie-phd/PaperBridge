添加新项目不会删除旧项目。这里会保留最近打开过的论文目录和主 TeX 文件。
2选择论文
将在 PaperBridge 数据目录中创建一个包含 main.tex 的空白项目。项目名称可以留空，之后仍可修改。
仅支持 HTTPS 地址。Token 只保存在此电脑，不会写入论文目录或 Git 远端地址。
导入时只连接并检查仓库，不会立即上传。确认论文无误后，再点击页面顶部的“推送”。
