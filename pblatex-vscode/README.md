# PBLaTex

PBLaTex is a VS Code companion for LaTeX Workshop. LaTeX Workshop remains responsible for the normal source editing and compile workflow; PBLaTex adds the bilingual paper-writing workflow already used by PaperBridge.

Open the PBLaTex activity-bar icon to access buttons for:

- connecting the current LaTeX workspace
- opening the complete bilingual workbench in an editor tab
- Chinese/English paragraph editing and translation
- fast preview and final PDF compilation
- AI review of the current TeX file or selected text
- searching references, inserting `\cite{}`, and adding BibTeX from a DOI or URL

The side panel is designed for frequent actions. The Command Palette entries remain available as backup shortcuts, but are not required for normal use.
